01 / THE QUESTION

一个方向，
不是一个动作。

如果模型说“向右”，我们还要决定每次走几毫米、何时停止、执行后是否真的靠近目标。这里的外层闭环是“观测 → 决策 → 执行 → 停稳 → 再观测”。

A / DIRECTION
＋ / ０ / −

Jev 负责方向

每个 XYZ 轴输出正、负或保持。它不会替我们提供连续位移，也不能仅凭输出的集中程度保证方向正确。

B / MAGNITUDE
0.7 × ‖e‖

函数负责幅度

现有共用规则按总位置偏差缩放，最大 10 mm；它沿 Jev 的非零符号向量均分，并不按各轴误差大小分配。

C / RESPONSE
u → Δx

05 / WHAT WE LEARNED

真正卡住的四件事。

动作函数已经可以让系统做局部位置闭环；下一步能否成为研究结果，取决于怎样分清信息、尺度和执行各自的贡献。

01

近目标容易过冲，也容易误判“保持”

堆叠数据中小误差配大步长会使误差增大。旧分阶段 gain 在 300 个开发验证状态上的动作选择与统一 gain=1 完全相同；离散幅度还留下近目标盲区。

↗
02

命令距离与真实移动不是一回事

LIBERO 旧近区零命令仍有 5–6 mm 在途运动；不同任务的执行响应也不同。我们随后只用停稳状态做近区比较，但仍没有跨任务通用的执行响应模型。

↗
03

精确坐标已经给出了直接方向

三初态闭环的原直接组曾因逐轴保持阈值与三维到达阈值不一致而落后。修正后它与 Jev+Q 的 10 步完全同轨；新的 8 初态再次得到 29 步同轨。

↗
04

任务前处理决定了偏差是否可信

本轮目标与阶段由旧 RGB-D 任务适配器固定，未重新检验目标估计、阶段切换或完整任务终局。奶酪初态也已在前一轮见过；这 8 例不能证明通用控制器已成型。

CURRENT POSITION

现在可以说什么？

共用 Q 在黑碗新初态的小样本里有有限局部优势；奶酪近区未见动作数收益。已有精确坐标输入让直接反馈给出同样的动作轨迹。局部到达不代表放盘或入篮的原生任务成功。
