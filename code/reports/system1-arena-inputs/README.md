# Complete System1-Arena Meta-World request example

This is a source-faithful reconstruction, **not a recorded author episode**.
Only simulator readings and episode counters are synthetic. All scene wording,
question instructions, option descriptions and API mappings are generated by the
reviewed original source at commit `28e16b16cdf68800a4cba148c3c6ea036f75bda3`.

- `metaworld-push-canonical.json`: complete `DecisionRequest`, including all 14 options.
- `metaworld-push-openai-body.json`: complete OpenAI request body; `input` is a JSON-encoded text string, not an image.
- `provenance.json`: source revision, reconstruction procedure and substituted values.

Original repository: <https://github.com/TianyuCodings/S1-Arena> (Apache-2.0).

Source locations:

- `s1arena/envs/embodied/tabletop_loop.py`: constants at lines 44–60, `options()` at 163, `observe()` at 174, `_PuckTask._point()` at 233, `Push` at 248.
- `s1arena/models/openai_decisions.py`: `to_decisions()` at 60 and request body at 92.
- `s1arena/envs/embodied/tabletop_loop.py`: `_drive()` at 119 computes low-level position error; that vector is not included in `observe()`.

The example uses `push-v3`, timestep 0.0125 seconds, decision 4, 32/500 simulation
steps, and a previous `z-5cm (reached)` result. Coordinates are illustrative.
The original constructor functions were extracted with Python's standard-library
AST and executed against substituted state accessors. No simulator dependencies
were installed, no robot was run, and no model endpoint was called.

Verification: 14 options in original order; serialized OpenAI input decodes to the
canonical state; the original adapter retains every option and its description.
JSON string sequences such as `\n` should remain escaped when copying the JSON.
