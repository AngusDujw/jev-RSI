# RoboDojo TCP action-interface audit — 2026-10-17

## Scope

Six positive single-axis movements of the right X5 arm in native RoboDojo physics and RGB rendering. No planner/advancer call, experience injection, real-robot connection or scene-object pose query is used. This is not a benchmark task result.

The shared description is in `code/contracts/tcp_action_interface.draft.md`. Local RealMan sources were read only: `model_description.txt` lines 3–15 and `embodiment.py` lines 175–183 / 214–219 in the local Inspect Robots RealMan plugin. Its per-arm +X-forward/+Y-left frame and negated-pitch ZYX interface must not be confused with the RoboDojo world +Y-forward/+X-right convention. The demonstrated single-axis yaw/pitch/roll names match RoboProbe world Z/X/Y.

## Physical result

Common TCP: approximately [0.25, -0.20, 0.95] m, fingers pointing down. Rotations hold the TCP target fixed and use world axes. Before each clip the robot physically returns to the common configuration; images are not generated by interpolating poses.

Simulation-state precision does not imply real-robot precision.
