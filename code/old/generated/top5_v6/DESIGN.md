For example, `Fold the clothes neatly.` may select one currently observed cloth with uncertainty at most 25 mm even when its visible description is `blue shirt` and its lexical score is zero. The task must be fold_clothes. Multiple candidates are rejected even if generic wording gives one a higher lexical score. Existing landmark and geometry requirements still apply after selection.

Before this exception, the existing unavailable-evidence check runs. For category-only folding, any rejected or retained unavailable cloth candidate in its scope blocks selection regardless of lexical score. Existing completed/stack-member exclusions and finite-memory TTL remain. Other categories retain v5 distractor scoping. Full-instruction matching prevents color, garment subtype, printed-identity or other added constraints from entering this exception; those requests retain v5 lexical checks. General pickup is unchanged: `Pick up the mint green scissors by10cm` cannot use this exception when scissors is unavailable. No nearest-object or arbitrary zero-score fallback is added.
