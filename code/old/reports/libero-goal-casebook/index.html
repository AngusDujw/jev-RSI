01 / INDEX

1144 等数字是什么？

它们是 LIBERO 的 libero_goal 任务索引（task-id），不是成功次数、随机种子或物体编号。例如 Goal1144 是“把碗放到炉面”，Goal1383 是“点燃炉灶”。同一个任务还可以有多个官方初始状态，另用 init-index 表示。

SUITE / 任务组libero_goalLIBERO-Plus 提供的 Goal 任务集合
TASK-ID / 任务索引1383“ignite the cooking appliance”
INIT-INDEX / 初态索引6同一任务的第 6 号官方初始配置

例如“Goal1383 init6”表示任务索引 1383 在初态索引 6 的一次回合；它不表示第 1383 次实验。

06 / SCOPE
这些成功说明什么
输入权限
Jev 输入由公开任务文字、渲染的 RGB-D、相机标定、机器人自身 TCP/夹爪反馈、机器人自身夹爪网格和动作历史构成。旋钮案例主要使用外部相机；斜架案例还使用腕部相机及本地视觉分割。预设阶段和几何候选是外部算法给的，Jev 决定所问的方向、夹爪、候选和阶段边。
成绩边界
success=true 与 program_finished=true 同时成立才算完整成功。官方成功判定只在终局评分，不在 Jev 请求里。1383 的冻结 5/5 中只有 4 个独立未见初态；1458 的冻结可评估新初态仅 1/1。它们不是跨全部物体、全部初态或真实机器人的成功率。
