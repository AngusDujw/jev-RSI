# 联合离散决策的输入经验候选（不自动加载）

来源：本轮 `code/runs/jev-discrete-*`，完整版本及逐回合信息见 `LOGS/jev-discrete-ledger.json`。只保存可复用规则和失败事实，不保存布局坐标或隐藏答案。

- 阶段问题应只评价当前阶段。SELECT只需可见目标和可用候选方案；不能因为尚未抓住或抬起物体而一直重新观察。同一general_pickup首帧的两次Jev重放支持这一措辞改动，但不能单凭重放声称闭环成功。
- 夹爪完全闭合可能被物体阻挡。闭合阶段提供实际开度序列及上次命令，让Jev决定是否试抬；不能将闭合程度当抓持成功，必须再检查视觉随动。
- 当前衣物/叠碗有空抬失败。普通5mm死区可能过宽；2mm航点跟踪、衣物可见点内缩10mm与接触降低4mm只是待验证几何候选，绝不当作感知误差已降到2mm。
- 关系输入必须声明参照和减法顺序。`signed_distance_mm`含义不够明确，一次叠碗关系输入出现三轴符号与估计误差相反；应明确`target_minus_current_grasp_mm`及单位转换。执行器不自动改Jev符号。该现象不能归因于所有关系输入，尚需同状态重放和闭环对照。
- 传送带记住首次出现，只代表可以进入等待离开的阶段；不是已经离开。等待离开、等待再次出现、允许接近，各自需要不同的当前证据。阶段候选在Jev未接受时必须持续有效。

完整联合请求重放补充：同一叠碗观测的原始请求两次都为0/3运动轴与估计误差一致；明确参照和问题文字后3/3，坐标版3/3。仅单一状态，不把模型confidence当物理正确率。首次三次探针因Python共享字典意外统一了问题文字，不作为原始请求对照；原始文件保留，之后深拷贝并断言原请求不变再重放。
