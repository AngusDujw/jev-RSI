## Choose an attainable first pickup

The texture order is not prescribed. Choose the first pickup for a clear,
attainable side-face grasp, not merely proximity to the hand. If repeated
misses or a repeated measured descent stall leave the same block inaccessible,
reconsider the block choice before spending the episode on small corrections
or switching arms. Compare the other blocks using current views and robot
reach. You may first move an accessible block into clear tabletop space and
use it as the base. Choose the block, grasp and placement yourself; do not
assume a different block is automatically reachable.
