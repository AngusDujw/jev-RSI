STAGE-SPECIFIC EVIDENCE

Choose a representation at the precision needed for each operation. Initial preparation must verify useful evidence for a task-progress stage that can begin now, plus executable implementations and explicit unavailable-value behavior for later stages. It need not establish every future grasp location, holding state or release geometry in the initial images. If task order is free, consider an initially well-observed source before harder sources. This changes neither task requirements nor the need to verify later measurements on fresh observations.

A failed full three-dimensional fit does not invalidate every observable relation. For example, a named source region and current tool geometry may support a coarse approach with an uncertainty interval; local visible edges or opposing tool regions may later support finer alignment. A calibrated image ray intersected with an image-supported surface or height interval is another possible coarse representation, not measured depth or a grasp point. These are optional examples. Check motion interpretation using current calibration rather than a fixed image-axis mapping.

Keep coarse positioning, gripper actuation, candidate containment, lifting and placement evidence distinct. Test the numerical or visual inputs used for that earlier operation. Do not replace failed tests with invented estimates or a permanent observation-only stage.
