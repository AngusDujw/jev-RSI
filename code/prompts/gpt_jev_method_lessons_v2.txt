Generic development lessons, supported only by the recorded development failure:

- Reference continuity is part of the runtime contract. A source repair does not
  reset the physical episode or its saved patch references. Store useful handles
  and their surface identity in checkpoints. A fresh update must still establish
  current quality; persistence does not certify object identity or attachment.
- For positive overlap m between a translated interval [a+t,b+t] and [c,d],
  feasibility is exactly c+m-b <= t <= d-m-a, provided
  0 < m <= min(b-a,d-c). A finite contact band can overlap a side even if its
  center or its entire band is not contained in that side. Intersect the relevant
  measured overlap and support-clearance constraints in a consistent frame.
  This mathematical identity is not evidence that physical contact occurred.
- A prospective motion test can start from a newly measured, identified patch.
  Its reference gauge need not equal an older full-shape gauge. Compare the
  independently observed patch motion with measured hand motion; do not substitute
  hand motion for an object measurement. Reconstruct a global shape pose only
  when a later action actually needs it. A safe observation-producing action
  still needs phase-local justification, not proof of an unavailable later state.
- With a known rigid planar shape, a measured face plane and an identifiable
  edge direction constrain orientation. An independent physical fiducial can
  resolve translation and finite edge-identity hypotheses. Use visible geometry,
  validate residuals and reject ambiguous hypotheses; do not invent hidden corners
  or require an entire old landmark set when sufficient independent evidence exists.
- Treat goal-pose tolerance and actual effect uncertainty separately. After a
  bounded pose lease, evaluate the relevant measured geometry before declaring
  an object-level outcome. A small residual is neither failure nor proof of the
  object effect. Do not double-count a future control allowance as an unobserved
  current displacement after the actual geometry has been measured. Heuristic
  uncertainty is not a calibrated multi-sigma certificate.
- Checkpoint acknowledged jaw transitions and phase intent before a later
  observation can fail. A repair must distinguish approach, possible holding,
  measured retention, and actual release. After release, a missing observation
  alone is not a reason to regrasp or disturb the object; seek bounded additional
  evidence or report uncertainty. Model proposals and native task scores differ.

- A valid reference patch can become untrackable after viewpoint or occlusion
  changes. An unknown registration is not proof of a lost object. Design a
  bounded current-observation fallback for each phase that uses registration,
  rather than only at initialization. Semantically defined, visually identifiable
  corresponding landmarks can provide independent motion evidence when their
  uncertainty and identity checks are adequate. If they are not adequate, seek
  another justified observation or stop. Never turn a command prediction into a
  measured object transform. Store the reference definitions and measurements
  before motion so a later fallback or repair can use their actual provenance.
- Check exact numerical-helper return fields before using them. In particular,
  a plane fit returns coefficients, not an undocumented alias for that vector.
  Early interface mistakes consume the same limited repair budget needed for
  genuinely new physical observations. An offline-valid source still requires
  real execution and native evaluation.

- Check that finite phase loops can cover the remaining work under the smallest
  progress leg actually used, including visibility fallbacks. Reducing a leg
  length without updating the route bound can make completion impossible even
  when every local action succeeds. View changes consume calls but are not
  necessarily target-directed progress. Reserve calls for later phases; a
  coherent budget is not a collision or convergence certificate.

- Scope prerequisites to the action being considered. Certifying an entire later
  transfer route is not a prerequisite for every earlier noncontact observation
  or approach. Each phase needs its own attainable evidence and bounded fallback.
- The runtime does not certify collision-free swept volumes. Distinguish visible
  obstruction, incomplete visibility, and certified clearance. Do not invent the
  third capability or make it an implicit mandatory sensor.
- If a needed view is missing, consider a bounded observation-producing action
  justified by the current local evidence, or return a specific capability gap.
  Repeatedly reviewing an unchanged occluded scene cannot create a new view.
- The robot's measured finger geometry and proprioception can support reasoning
  about its own envelope. They do not prove object contact or retained load.
  Ask visual reviews for the missing object evidence, not for information already
  available numerically about the robot.
- Match measurement requests to the published review capacity. Use supported
  named point/region fields; arbitrary metadata is not an executable sensor.
- Prefer a concise complete method with useful local checks and recovery over
  a long list of redundant global gates. None of these lessons proves that the
  next generated method will complete the task; actual execution is required.
- Report the numerical values behind a failed geometric check in trace notes or
  result evidence. Arbitrary fixed object-size ranges are not physical laws.
  Derive grasp clearances and margins jointly from measured object dimensions,
  own finger geometry, measurement uncertainty, and controller tolerance. A valid
  small object can make independently chosen fixed margins mutually infeasible.
- A depth sample at a visual boundary can hit an adjacent surface. Check
  consistency with an interior measured surface rather than assuming all marked
  corners have equally reliable depth. Current calibration and a fitted plane
  support explicitly derived ray intersections for genuinely visible planar
  landmarks, with the plane-fit uncertainty and correspondence limits retained.
- Jev never sees a question's dictionary ID. Identical axis question text with
  identical criteria does not identify six different axes. Specify each subject
  and feature selector in question content. The control compiler now binds the
  axis selector explicitly; arbitrary branch questions still need self-contained
  instructions. Two real zero-motion comparisons supported this fix on one
  stored state; they are not task-success or general direction-accuracy results.
- Camera-relative corner names are not persistent physical identities. Supply
  semantic landmark definitions and reference observations/geometry to subsequent
  reviews, or implement uncertainty-aware correspondence from available data.
  A changed view must not silently redefine which physical point an ID denotes.
  Historical projections assume stationarity and must not be treated as current
  object measurements after manipulation.
- Closure can hide the outline while leaving a textured interior patch visible.
  Requiring a complete perimeter before a justified retention-measurement lift
  can create another circular precondition. The RGB-D registration primitive
  was checked on synthetic translations/outliers and on recorded pregrasp/closure
  views with partial occlusion. That is measurement evidence, not a completed
  physical task or a universal tracking guarantee; unknown still needs recovery.
- Initialize a reliable textured reference before a motion that occludes it when
  possible. A camera suitable for an object's geometric outline need not be the
  best camera for texture registration. Keep each ROI tied to its own camera and
  observation frame; inspect feature-count errors and choose a better visible
  interior patch rather than blindly repeating the same inadequate selection.
- Use exact response field names from the current manual and actual receipts.
  A descriptive phrase such as current observation does not imply an additional
  current_frame_id key: the tracker uses frame_id and reference_frame_id. Include
  relevant measured values in evidence before a later operation can fail; a
  method repair starts a fresh Python namespace while physical effects persist.
- A gate labelled clear can silently require complete visibility even when the
  requested fact was only absence of a visible external obstruction. Ask for
  separate obstruction and visibility evidence with defined decision meanings.
  Repeated observation moves that preserve the same self-occlusion do not resolve
  that uncertainty. Use a justified local action or a genuinely different view;
  never replace unknown with certified clearance. Preserve valid historical
  geometry explicitly instead of rebuilding every unrelated prerequisite after
  a repair. These lessons do not authorize motion through an observed obstacle.
