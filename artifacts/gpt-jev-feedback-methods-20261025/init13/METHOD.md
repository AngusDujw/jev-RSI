# Actual complete GPT method: initial state13

The final source and final interface are authoritative. Model descriptions below are preserved verbatim. Earlier design/rationales are historical, not additional runtime instructions.

## Final interface

main(api) and its JSON result are preserved. Existing non-economical processing and Jev questions remain unchanged.

Gate dependencies:
1. Preclosure requires the actual open-hand state, pad overlap, aperture and support margins, identified carton face, and local closure/upward-motion interpretation. For this repair only, the frame-519 review is reusable when the saved run provenance, physical frame and measured TCP match. Its two visible surface samples are measured again. The rectangular face is a short-horizon hypothesis, checked against those samples and the visible edge. No additional descent is required by the small pose residual. Any different physical frame disables this reuse.
2. Local motion reference requires an identified rigid carton surface, not registration to all historical landmarks. A saved usable tracker is tried first. Otherwise the visible printed end surface is selected rather than the failed lower strip. The two physical end-edge corners and the printed end-face emblem define an independent semantic reference; boundary points use the already validated face plane and calibrated current rays. Failed depth measurements remain absent. Tracker quality checks remain mandatory.
3. Closure establishes possible holding only. The baseline is checkpointed before closure. The bounded upward test uses the already reviewed local ascent and compares independently observed corresponding points with actual hand motion across closure and lift. Full-envelope pose is not a prerequisite for this test. An unknown post-test registration is deferred to recovery, not converted into attachment or loss.
4. Before additional ascent or transport, an adequate current envelope and independent motion evidence are required. Recovery requests the saved physical correspondences and a different usable current patch. A sufficiently observable rigid fit can establish the new patch-to-envelope relationship, after which its reference is rebased and checkpointed. Ambiguous correspondence, inadequate spread, or unavailable envelope evidence stops transport. This fallback does not invent hidden corners or a transform.
5. Transport requires measured retention, current lowest object/finger extent, the measured rim and bowl opening, and local external-obstruction evidence. A recovery review may also assess the bounded remaining ascent, above-rim centering, numerically gated opening, and upward retreat. Such an assessment is a historical scoped prior, not a fresh observation at reuse. The original native-step timestamp is retained; the 45-step expiry and all numerical gates remain active. Self-occlusion, unobserved space and an observed external obstacle have separate meanings. If no usable cached assessment exists, a fresh transport review is allowed only while preserving the final review.
6. Release and final verification retain the existing fresh-envelope fit/height checks, one bounded correction, acknowledged jaw transition, upward view change, actual supported-inside review, and independently measured post-release stability interval. Missing evidence after release never triggers regrasp.

The ordinary continuation uses no additional preclosure review and preserves the remaining two reviews. Control leases, contact counts and reserves remain bounded. A recovery assessment replaces, rather than adds to, the transport review. Persistent records remain bounded: one run record, one economical state, existing references and one reference candidate. Numerical failures and exact unresolved evidence gaps are returned; completion remains a proposal, not native success.

## Final Jev input/output cooperation

The seven existing control questions are unchanged. Each translation/rotation question uses its compiler-bound world-axis increase/decrease/within_tolerance relation, with exactly negative, hold and positive choices. The gripper question uses exactly open, close and keep. Python calculates all targets, magnitudes, tolerances, pad/TCP offsets, geometric margins and independent motion errors. api.drive supplies bounded pose-feedback leases; jaw transitions use api.control. Neither a reached receipt nor a delivered closure establishes an object effect.

Every actual api.review call retains explicit structured fields. The optional combined registration/transport review asks for exact, ambiguous or unavailable physical correspondence; external_obstacle, none_observed or unknown obstruction; observed, partial, self_occluded or unknown visibility; supported, unsupported or unknown local action; stationary-world consistency; load appearance; and a camera/current polygon or null. It receives measured robot state, saved semantic definitions, historical reference geometry, the bowl/table measurements and the ascent ceiling. These historical inputs are explicitly not current detections. Reusing this review preserves its timestamp and scope. The final review still distinguishes supported_inside, bridging, outside, held and unknown. Unknown evidence is never mapped to clearance, attachment or success.

## Original complete model design (historical if revised)

The method treats the runtime request as a semantic item/container relation, not a stored trajectory. It measures a supported rectangular carton and the bowl opening, derives an open-jaw approach from the actual pad offset and opening axis, and tests retention using independently observed rigid-surface motion versus measured hand motion. The ordinary path does not require visible carton corners after closure. A persistent RGB-D patch reference, with semantic point correspondences as an independent fallback, supports local motion tests. A replacement patch can start a new prospective test without registering to the old carton envelope. Full envelope information is recovered only for centering and release.

The robot carries the carton above the bowl, checks that its measured projected envelope fits the opening, and opens with both the carton underside and the opening fingers above the rim. This is a bounded gravity-assisted placement, not an assertion of supported contact before release. A retracted view and two separated observations assess the actual object/container relation and stability. Failures preserve the current jaw state, references, acknowledged transitions, and diagnostic evidence; they do not silently undo motion or declare success.

## Model revision1 rationale (historical)

The recorded failure occurred before any physical action. The measured opening-minus-carton radial margin was 0.0066332 m, but initialization required 0.007 m because it added an unrelated fixed 0.004 m allowance to the uncertainty margin. The later release gate did not require that allowance. This patch separates initial controller allowance from the actual measured release margin: initialization reserves an attainable centering tolerance from the remaining geometric slack, while release checks the current envelope without subtracting a future controller allowance again.

The measured grasp-height interval was also only 0.001068 m wide. Targeting its lower endpoint with the old 0.001 m tolerance was inconsistent with that interval. The repaired method targets the interval midpoint, derives a compatible grasp tolerance, uses that tolerance in both the feedback lease and its stopping condition, and checks actual pad-band overlap and finger/support separation before closure. The minimum supported controller tolerance is enforced rather than silently requesting unattainable precision.

Directly coupled executable defects are repaired: nested string-array schemas now use proper item descriptors; robot self-occlusion does not automatically halve an otherwise justified local leg; expected post-release settling is not classified as pre-release load loss; and release-height margins use current uncertainty and the highest measured rim sample. Existing patch tracking, independent retention measurements, bounded recovery, checkpoints, Jev questions, and post-release verification remain in place. No motion or successful placement is claimed by this revision.

## Model revision2 rationale (historical)

The failure occurred at frame 0, before any physical action or tracker initialization. The method incorrectly required a three-landmark triangle to pass a full-pose conditioning threshold before trying the independently selected textured patch. The recorded landmarks can provide a differential motion witness even when their narrow spread is inadequate for a precise envelope rotation estimate.

This patch separates those dependencies. Tracker initialization no longer depends on semantic landmark spread or successful measurement of every fallback landmark. Direct, identified landmark correspondences can support local retention tests without fitting a global transform. A full transform is required only for envelope propagation; inadequately conditioned semantic registration then falls back to a fresh visible-face measurement. Useful tracker handles, surface identities, measured reference points, and conditioning diagnostics are checkpointed. Unknown registration still requires independent observations, never predicted hand attachment.

The saved, accepted plan is reused only when its checkpoint frame exactly matches the current physical frame. Its support and bowl measurements need not be repeated merely because Python restarted; the missing carton envelope is measured again and checked against the saved dimensions and height. Small directly coupled budget changes reserve observations for completion: a single 25 mm prospective lift, 70 mm unheld legs versus 50 mm held legs, and no automatic shortening solely for partial visibility when the reviewer has explicitly justified the proposed local leg. Unknown visibility retains the shorter bound. Checkpoint strings and landmark definitions are also bounded. This revision proposes no successful grasp or placement; those remain runtime measurements.

## Model revision3 rationale (historical)

The last descent was correctly rejected: the open bowl-side finger would cross the visible rim. No closure or descent followed that rejection. The repair does not reinterpret that obstruction as occlusion or repeat the blocked descent. It computes an alternative grasp site along the currently measured carton face, preserving orientation and allowing a deliberate offset from the carton centroid. Candidate sites must retain sufficient side-band overlap and aperture clearance. A conservative bowl-distance calculation ranks alternatives, but a fresh local review must still assess the actual outer rim and finger corridor. The hand first relocates above the rim before descending at the selected site.

The directly coupled budget problem is also repaired. Eight-call drive leases were causing repeated reviews of partially completed legs. Eighteen-call bounded leases allow ordinary pose feedback to finish more local legs without repeatedly purchasing the same observation. Review reserves now explicitly protect preclosure, retraction, and the two final observations. Existing independent retention tests, tracker recovery, release geometry, and post-release verification remain in place. This patch is not a motion receipt or a claim of successful placement.
