# Review contracts

For every finding below, **inputs/frames** include documented request/response schemas, exact returned fields/errors, action scope, current state/acknowledgements and camera/frame provenance. Pixels are camera-local; metric fields retain meters/radians. **Responsibilities:** reviewer identifies visible relations; program validates schema, meaning and applicability; Jev acts only on the resulting bounded numerical request.

## A. Unknown is neither contradiction nor approval

**Status:** verified for two episode-1 gate misinterpretations; recommended safeguards are not an isolated success experiment.
**Applicability:** Initial entry, temporal comparison and same-frame recovery.

Separate identity/support, temporal change, route, contact feasibility and effect completion. Use exact enums such as yes/no/unknown, clear/blocked/unknown and unchanged/changed/unknown. Do not use string truthiness, boolean/string comparison or similarly named fields.

A single initial view cannot establish temporal stationarity. Create a baseline instead of repeating that question. Unknown change does not negate separately affirmative current support and a scoped noncontact route, but cannot authorize a segment requiring stationarity. Same-frame reuse needs reconciled state and applicable dependencies; unchanged robot counters alone do not prove external stationarity. Refresh affected comparisons after motion.

**Stop:** malformed/ambiguous fields, stale dependencies or unavailable required evidence. Inspect a conflicting blocking reason before another review; never repair it by making unknown equal yes or suppressing contrary evidence.
**Evidence IDs:** N-J1, N-J3, N-G acquire.supplement, N-M02, N-M04, N-PLAN.

## B. Closing dimension is not contacted-edge length

**Status:** scene-specific semantic failure and clarification.
**Applicability:** Rectangular objects with ambiguous short-side/end-face wording.
**Additional inputs:** measured object axes, visible face identities and closing direction.

Closing across the short dimension opposes long lateral sides; closing across the long dimension opposes short end faces. Name both the motion axis and contacted surfaces. T reached standoff, then received bracketed=no because the question requested short ends while jaws opposed long edges. The route was separately clear. A fresh explicit long-face review preceded descent.
**Stop:** ambiguous identities or unsupported bracketing. Do not reinterpret no as yes or reposition solely to satisfy a mistaken label.
**Evidence IDs:** T-J1, T-M01, T-M02, T-G.

## C. Submission failure is not geometric evidence

**Status:** verified for the repeated hazard: two T reviews exhausted native repair on out-of-schema region stride. Internal repair attempts are not separate trials.
**Applicability:** Structured review services with finite validation/repair budgets.
**Additional inputs:** native field constraints, camera resolution, error path and valid observation receipt. Stride is a schema sampling parameter, not world distance.

Request only needed channels. If bounded points suffice, omit regions/clouds using the documented contract. Supported alternatives include typed pixel arrays followed by direct point-depth calls, or bounded named native points with empty regions. Validate actual responses, not merely request intent. Use documented per-camera pixel bounds and allowed stride, not guessed values. Schema-valid samples still need identity, depth, finite-coordinate and frame checks.

One parameter-only/direct-depth revision reached standoff; later named-point/no-region requests returned baseline and post-lift reviews. These repairs are scene-specific, not proof that avoiding regions alone is sufficient. Method-07's interface claimed empty native fields but execution failed on a region stride; omitted source prevents diagnosis of that discrepancy.

**Stop:** invalid submission or absent valid observation blocks dependent motion. Reconcile actual progress before repair; bound retries and count synthesis/repair/supervision costs. The first failure preceded motion; the second followed closing progress. Neither proves obstruction or failed retention.
**Evidence IDs:** T-J0, T-J1, T-J7, T-M00, T-M01, T-M07, T-M08, T-RBASE, T-RLIFT.
