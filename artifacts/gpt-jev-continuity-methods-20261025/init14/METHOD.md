# Actual complete GPT method: initial state14

The final source and final interface are authoritative. Model descriptions below are preserved verbatim. Earlier design/rationales are historical, not additional runtime instructions.

## Final interface

Entrypoint: main(api). The current episode instruction is bound as task text; no task file, hidden object state, saved trajectory, or native evaluator is read. Uses only documented state, review, plane_point, tracker, compose, checkpoint, recall, note, control, and drive calls, plus the supplied numerical helpers and NumPy. All physical requests use the pad_center target convention; TCP-to-pad conversion and actual finger offsets are kept distinct. Review requests declare exact typed fields and named RGB-D measurements, check measurement_errors and membership, and reject inadequate geometry with numeric diagnostics. The initial rectangular-package and circular-bowl models are conditional on current visible evidence; unsupported geometry produces a limitation rather than invented hidden surfaces. Checkpoint key measured_transfer stores the task, measured reference geometry, landmark definitions, tracker creation receipt and reference transform, phase intent, acknowledged jaw transitions, retention baseline, and bounded evidence. The result is JSON-compatible with completion_proposed and evidence, with phase and limitation on failure. Completion is a proposal based on observed placement and a bounded stability interval, not official task success.

## Final Jev input/output cooperation

Each physical update sends seven finite-choice questions. The x,y,z,rx,ry,rz questions explicitly identify their world-axis subjects and the corresponding state.processed_features.axes.<axis>.goal_relation selector. Jev chooses negative for decrease, positive for increase, and hold for within_tolerance. The runtime maps these unchanged choices to -1, +1, or 0 times its residual-derived, L2-bounded magnitudes, respecting the documented per-axis deadband and world rotation-vector sign. The gripper question explicitly reads state.processed_features.objective.gripper and chooses exactly open, close, or keep. Program features contain phase, local obstruction/visibility interpretation, and measured uncertainty; trusted runtime state supplies current pose and residuals. Jev is not asked to compute transforms, infer contact, see undeclared images, or certify collisions. Ordinary moves use bounded drive leases, which still call real Jev at every control update. Jaw delivery and post-release observation intervals use individual control calls. Reached means only measured pose and command delivery; moved is accepted only within the bounded pose checks, stalled stops further pushing, and lease exhaustion requires measured useful progress. Separate typed image reviews provide physical object evidence and distinguish external obstruction, none observed without certification, unknown external space, and self-occlusion. Tracker or independently identified landmark measurements, compared with actual robot motion, gate retention; fresh post-release observations gate placement and stability.

## Original complete model design (historical if revised)

This method measures the package, its support, and the bowl from the current RGB-D views. It uses a conservative side-pinch plan derived from the actual finger geometry, preserves the current orientation when feasible, tests retention by comparing independently observed package motion with measured hand motion, and transfers above the measured bowl rim before releasing. The tracker is optional: identified physical landmarks provide an executable registration fallback and can initialize a replacement patch. Local visual reviews distinguish external obstruction, incomplete visibility, and self-occlusion; they do not purport to certify a whole motion corridor. Checkpoints preserve reference provenance, acknowledged jaw transitions, and retention-test baselines across repairs. Final completion requires fresh evidence of placement and short-term stability after release, not merely a reached pose.
