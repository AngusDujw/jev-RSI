## Explanation

This is a runtime, measurement-driven pick-and-place method for the requested rigid package and open vessel. It does not embed the supplied pixels, dimensions, poses, or a trajectory. It first establishes a tabletop, a visible package face and envelope, and an identified inner rim. Grasp selection uses the measured side height, the actual pad offset, the tool-y opening axis, and the open finger envelope. A delivered closure is recorded as possible holding, not successful grasping. Independent RGB-D patch or corresponding-landmark motion must agree with measured robot motion during a bounded lift. Local motion references can be replaced without first recovering all old corners; a later envelope recovery uses a current face and one complete physical edge, retaining finite dimensional hypotheses. Transfer and release use separate footprint, height, and opening-finger checks. The final proposal requires observed separation, seating inside the vessel rather than rim bridging, and stability across physical steps and a withdrawn view. Unknown observations trigger bounded alternative measurements or an explicitly justified view/probe action. Checkpoints preserve acknowledged transitions and reference provenance across repairs. The method stops truthfully on an unsupported geometry model, observed obstruction or loss, exhausted evidence, or resource limits.

## Interface

Entry point: main(api), with only documented runtime operations, np, math, and geo. The runtime instruction and current images identify the roles; the method supports a rigid rectangular item initially supported flat on a table and an approximately horizontal circular vessel opening. Unsupported models return an explicit limitation. Output is JSON-compatible completion_proposed plus evidence; it is not native success.

Observation dependencies and gates:
1. Initial geometric model: requires same-body identity, the visible rectangular face, its supported-bottom interpretation, local table plane, inner rim, and cavity evidence. Witnesses are two interior RGB-D regions, four visible face-corner pixels intersected with the measured face plane, distributed inner-lip points, and an interior-bottom point. Region adequacy, rectangular consistency, rim coverage, plane orientation, measurement membership, and measurement_errors are checked. Surface measurements are not silently treated as centers or undersides. Failed measurements get a bounded alternate-view/region request.
2. Approach and closure: requires the current package envelope, tool-y opening direction, actual pad-center offset, side-band overlap, and the open finger/table clearance. The opening computed from joint span and aggregate pad width is explicitly a candidate-ordering proxy only. A fresh local review must independently observe/model the actual open pads straddling the side faces before closure. Optional measured inner-pad points report the actual visible gap. A finite search considers two jaw axes, two overlap fractions, and three band heights. The midpoint maximizes vertical slack; center placement preserves lateral symmetry. The contact-band constraint is the interval-overlap formula, not complete pad containment. Missing old corners do not block local closure evidence. Unknown alignment gets a different local witness request; unresolved evidence prevents closure.
3. Prospective retention test: requires a currently identified rigid local surface reference and a justified short upward action, not already-proven holding or a visible entire perimeter. The tracker is initialized on a current interior polygon. Its handle, surface identity, camera, creation provenance, reference frame, optional semantic texture marks, and envelope relation are checkpointed. Inlier fraction, inlier count, residual, feature spread, and uncertainty are checked. A fallible tracker can be replaced by exact current semantic landmark correspondences. Same-body identity and correspondence are separate fields. If both fail, another current patch establishes a new local gauge; a new prospective lift is then necessary. No old-to-new transform is invented.
4. Retention and transfer: corresponding independently observed local points are compared with actual pre/post robot states using geo.attachment_error. Observed rise and sufficient actual hand motion are separate requirements. Closure, controller arrival, and tracker existence alone prove nothing. The local test uses local uncertainty, not full-envelope uncertainty. Three total prospective tests and two grasp attempts bound recovery. A failed lift permits opening and retry only after independent evidence that the package is on the original table and separate from the raised pads. Unknown holding preserves closure. Transfer has a fresh differential attachment check; unknown registration invokes the same local-reference/prospective-test recovery rather than an unconditional global registration.
5. Envelope-dependent transport and entry: only these gates require the transported extent. An existing measured patch-to-envelope relation is propagated with a heuristic angular lever-arm allowance. If unavailable, a current planar face and one fully visible physical edge recover a rectangle using measured invariant dimensions; possible edge-length/side hypotheses are retained as an envelope union. This does not require registration to every old corner. Unobservable unused corner indices do not invalidate a symmetry-invariant envelope. If this local reconstruction is unavailable, the exact missing evidence is reported. Dimensional, local-registration, and destination uncertainties are recorded separately; heuristic bounds are not calibrated confidence intervals.
6. Local motion permission: review fields separate observed external obstruction, visible/partial/unobserved space, robot/item self-occlusion, and the basis for a local geometric model. Absence of observed obstruction is not a collision certificate. A supported partial model may justify the actual local action; no complete future-corridor visibility is demanded. An unresolved local gate can perform one explicitly justified 15 mm vertical view action and then reobserve. External obstruction forbids the rejected motion. A view change is never object-motion evidence.
7. Stationary vessel prior: rim geometry is retained only across noncontact above-rim actions while current partial lip points and identity observations agree. Changed, unknown, or inconsistent evidence invokes a new inner-rim/cavity fit. The support plane is a fixed-table model, not a hidden collision map. Possible package contact invalidates package stationarity; its next use requires current motion evidence or current envelope recovery.
8. Release: requires a newly measured footprint within the inner opening and actual package/finger height above the lip. The open finger envelope, not just the currently closed fingers, determines opening clearance. Two geometry-derived corrections are allowed. A failed uncertainty proxy triggers current envelope/rim refinement or an explicitly described nominally feasible above-rim trial, not a declaration of physical impossibility. Actual measured geometry is evaluated after the pose lease without charging future controller error again.
9. Completion: an acknowledged opening is followed by fresh object-relation observations, upward withdrawal, and temporally separated measurements of a physical landmark plus orientation review. The item must be supported inside, not bridging the rim; the hand must be separated and the vessel upright/stable. Missing postrelease evidence causes observation/settling, not blind regrasp. Completion remains a proposal.

Persistence and bounds: run, geometry, reference, probe, verification, and evidence are separate checkpoint keys. References contain sparse points/envelopes and at most eight motion-test points, not clouds or nested histories. Diagnostics retain twelve entries. Intent precedes motion; acknowledgments and jaw transitions precede fallible sensing. Repairs reuse saved tracker handles only with a fresh update, distinguish possible holding from release, and revalidate affected evidence. At most 20 reviews, 180 physical controller decisions, three local lift tests, two grasp attempts, two release corrections, and bounded pose leases are used, subject to smaller runtime budgets. Four reviews and 25 early motion decisions are reserved for later verification/recovery. API errors stop with the acknowledged physical state preserved; measurement-specific errors are handled locally. Stalled motion is not repeatedly pushed.

## Jev protocol

All physical updates are api.control calls, directly for jaw transitions or through bounded api.drive leases. Every call supplies exactly x, y, z, rx, ry, rz, and gripper questions with the documented choice keys. Each axis instruction names its world-axis subject and uses the compiler-bound goal_relation selector. Increase maps to positive, decrease to negative, and within_tolerance to hold. Rotation signs are world rotation-vector signs and quaternions are xyzw. The gripper question maps the explicit objective to open, close, or keep; Jev's returned choice is dispatched unchanged and is checked in the acknowledgment. No question asks Jev to compute a metric, discover an obstacle, execute Python, or act as an undeclared visual sensor.

The program computes world geometry, plane/rim fits, transforms, pad targets, quaternion changes, overlap intervals, candidate ordering, uncertainty allowances, footprint slack, motion residuals, attachment errors, and control tolerances. Controller features identify the physical phase, the local pad-center objective, the relevant evidence frame, and the distinction between command delivery and object effect. The host supplies trusted current robot state, objective, per-axis signed residuals, and increase/decrease/within_tolerance relations. api.drive handles ordinary bounded feedback; direct api.control handles acknowledged jaw transitions. Returned before/after arrays are not treated as state dictionaries: full states are acquired independently for attachment tests. Reached means pose/command delivery only; moved is accepted only as an acknowledged bounded update; lease exhaustion is bounded; stalled causes an explicit stop rather than repeated pushing.

Visual interpretation is obtained separately through typed api.review fields and named measurements. Every review declares only its requested branch parameters, with explicit unknown or ambiguous outcomes. The questions define same-body identity separately from physical-mark correspondence, external obstruction separately from self-occlusion and unseen space, supported seating separately from apparent centering, and separation separately from jaw command. Requested points/regions can be absent, and measurement_errors are recorded before geometry is used. Historical reference definitions and coordinates are passed as reference context, never substituted for current detections. No optional tracking primitive is the sole retention gate when identified corresponding landmarks can supply independent motion evidence.
