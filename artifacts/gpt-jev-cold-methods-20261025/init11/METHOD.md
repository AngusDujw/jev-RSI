## Original complete model design (historical if revised)

This method interprets the requested object and receiver from fresh RGB-D reviews, rather than using image coordinates or a stored trajectory. It measures the package top, a visible side, its supporting table, and the bowl's inner lip. It explicitly treats the inferred package bottom as conditional on observed table support. Grasp height, jaw alignment, clearance, lift, transfer, and release height are calculated using those measurements and the supplied finger geometry. A textured patch tracker is initialized before contact. Retention requires independently observed object displacement consistent with actual measured hand displacement, not closure or tracking alone. Unknown registration triggers a bounded, semantic-landmark registration fallback, which can also establish a new current tracker reference. A failed grasp can be retried once only when measurements establish that the package remains supported on the table. The method keeps phase checkpoints, never automatically reopens during a held transfer, distinguishes external obstacles from self-occlusion and unobserved space, and reserves resources for release and verification. Completion requires fresh post-release observations of the actual object-in-bowl relation and a stationary identifiable object feature. This proposes completion; it does not access or claim the native evaluator's success decision.
