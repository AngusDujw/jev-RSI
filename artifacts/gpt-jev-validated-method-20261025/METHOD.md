The existing seven Jev control questions and exact choice keys are unchanged. Each x/y/z/rx/ry/rz question explicitly selects its host-provided axis goal_relation: negative means decrease that world coordinate or world rotation-vector component, positive means increase it, and hold means within tolerance. The gripper question selects the requested open, close or keep objective. Actual Jev choices are dispatched unchanged through api.control, including all api.drive updates.

Python computes pad-center targets using the supplied pad offset, xyzw orientations, geometric candidates, tolerances, plane/edge transforms, uncertainty features, actual hand rotation change and independent attachment errors. Jev receives current host residuals plus phase, action label, retention status and explicitly historical object observations. It is not asked to calculate metric geometry or infer image evidence. Existing ordinary feedback limits remain 0.02 m translation, 0.08 rad rotation, three native steps per update, 0.0025 m position tolerance and 0.035 rad rotation tolerance. Transition pulses retain their existing bounded checks and immediate jaw-acknowledgment checkpoints.

Structured visual reviews provide physical identities, measurement selections and phase-local action judgments. Repair mode explicitly distinguishes an open grasp-ready hand from an unapproached supported object. Local retention reviews may select new marks on the exposed end face; unavailable marks are omitted rather than invented. Envelope reviews distinguish a top face from an upright side face and require physically identified adjacent top-edge endpoints, never screen-relative corner renaming. The optional extra view review distinguishes observed obstruction, none observed and unknown, and authorizes only an informative locally supported upward action. After that action, a separate measured correspondence check is mandatory. Completion is still only a proposal based on actual released-object evidence, not native evaluator feedback.

## Last model revision explanation

The failure occurred after the acknowledged open-gripper descent, not because an obstruction or grasp failure was observed. The method incorrectly demanded a fresh full package pose before proceeding to a separately observable local closure and retention test. This patch recognizes an actually observed grasp-ready configuration on repair, does not replay the descent, and removes full-envelope registration from the ordinary post-descent path. It also repairs the directly coupled evidence requirements: a small orientation-preserving retention test can use one or more uniquely identified current physical marks, with optional qualified RGB-D tracking; it need not recover three old landmarks. For subsequent envelope-dependent transport, a measured face plane and two identified adjacent top-edge endpoints can recover the known rigid package envelope without seeing its entire perimeter. A failed envelope recovery has one explicitly justified, informative upward-view trial, followed by an independent object-versus-hand motion check and another measurement attempt. Existing grasp search, Jev questions, contact acknowledgments, release and final verification are preserved.

## Initial model design explanation (historical)

The archived run stopped before contact because a centered open-finger descent approached the neighboring bowl rim. This revision does not replay that run or load its measurements into the new episode. It measures the current scene, searches a bounded set of longitudinal grasp offsets using the actual pad band and full finger envelope, and ranks them by separation from the measured bowl lip. The score is explicitly a planning proxy, not observed clearance. Up to three distinct candidates can receive local visual assessment; a rejected descent is never executed. This permits an end-biased grasp with adequate finite pad/side overlap instead of treating the first centered grasp as the only configuration.

Directly coupled repairs separate the retention test from full-envelope registration. After closure, newly identified visible printed marks and an optional textured patch form an independent local motion reference, without requiring the old package corners or old printed marks. A measured test lift must produce object motion consistent with actual hand motion. Full package-envelope geometry is recovered only when transfer needs it, with an additional current planar-face/boundary fallback when the old landmarks are hidden. Tracker references and local test provenance persist across repairs, and acknowledged jaw transitions are checkpointed immediately. Final release, settling, containment and hand separation remain independently assessed.
