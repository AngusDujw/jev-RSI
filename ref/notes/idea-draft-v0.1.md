**候选题目：从定性决策到定量关节控制：反馈驱动的动作优化与调用复杂度**

*From Qualitative Decisions to Quantitative Joint Control: Feedback-Driven Action Optimization and Query Complexity*

## 1. 一句话与摘要

**人话的一句话：模型知道大致往哪走，我们研究怎样让它少试几次就走到，并说清省下的尝试来自哪里、在哪些条件下才成立。**

**研究表述：**以 Jev 为案例，将黑箱模型的关节动作判断视为有误差的方向信息，用反馈驱动的动作生成函数产生具体关节增量，研究方向质量、局部响应和采样／校准成本如何共同决定达到目标精度所需的总调用成本。

**摘要草稿：**快速决策模型使低延迟的闭环机器人决策成为可探索的方向，但输出合法、方向看似合理，并不等于能以低成本完成连续控制。我们拟研究一种方向决策与定量执行相分离的关节控制框架：黑箱模型根据当前任务阶段和观测提供动作判断，一个类似优化器的函数结合当前姿态与历史执行反馈，生成下一组具体关节角增量。在明确动作约束、观测条件与成本口径后，我们首先刻画方向质量、校准误差和局部几何条件如何影响单阶段的进展及迭代上界，再设计轻量实现检验这些理论量能否预测真实的调用成本。在统一成功标准与执行预算的对照中，评价对象包括模型请求、候选动作评估、实际试探、失败轨迹与墙钟时间。论文拟贡献是一个可检验的理论—测量—控制对应关系，以及在真实黑箱接口下对其有效范围的验证。能否实现节省、是否足够新颖，目前均待证明。

## 2. 研究问题、范围与贡献候选

录音最明确的研究问题是：**给定只能提供定性方向的决策模型，需要什么可验证条件与多少额外反馈，才能降低达到目标的总决策成本？**

建议第一篇先处理固定任务阶段下的局部运动，再把多个阶段组成抓取任务做外部验证。碰撞、接触切换、姿态表示奇异性与阶段识别失误需要单独处理；不能将一个平滑位置误差函数的结论推广到完整操作任务。

候选贡献按重要性排序：

1. **明确问题与测量协议。**分开模型方向、执行器能力、反馈校准及成本，给出能复现、能被反例推翻的定义。
2. **建立可落地的条件式成本关系。**将方向可靠性、反馈估计误差和局部几何连接到进展与调用成本；关键是有限反馈下的可估计性，不能停在假设已知梯度的理想推导。
3. **用轻量实现和强对照检验。**判断理论能否预测哪些场景受益、何时校准成本抵消收益，以及是否确实需要模型的方向信息。

VLA＋残差保留为另一条研究路线；首稿不把它作为必需结构。RLCD 后训练与跨领域推广属于后续方向，本稿不假设能取得模型权重或训练接口。

## 3. 新颖性约束

残差控制与符号优化都已有相关工作：[Residual RL](https://arxiv.org/abs/1812.03201)、[signSGD](https://proceedings.mlr.press/v80/bernstein18a.html)、[符号梯度的几何分析](https://arxiv.org/abs/2002.08056)。尚需系统核对自适应视觉伺服、在线 Jacobian 估计、带噪方向搜索与反馈优化，才能确认研究空白。

尤其需要留意：一个公开 Jev 机械臂项目已经把方向选择与分档步长执行分开。[项目说明](https://github.com/openroboto-ai/jev-robot-control#what-the-models-control)。因此，“给 Jev 加可变步长”目前不足以单独支撑创新；这是基于已有实现的判断，不是完整查新结论。

**本稿的可检验 gap 候选：**在黑箱、方向可能错误、执行反馈有成本的条件下，如何用可测量的方向质量与响应估计得到具有预测力的成本关系，并把校准开销纳入比较。

## 4. 方法骨架（提案）

先把一次闭环拆开：

观测与任务阶段 → Jev 方向建议 → 定量校准 → 执行器 → 新观测与实际进展。

- **坐标与信息。**按用户确认，令 q∈R^m 为当前关节角，m 是实际可控关节数；x=h(q) 为夹爪的位置／局部姿态，x* 为当前阶段目标，o 为观测。关节角统一用弧度，并规定各关节的允许增量。所有方法必须获得同等观测。
- **方向。**若沿用录音中的负／零／正接口，记模型输出为 s∈{−1,0,+1}^m；这是关节坐标中的建议，不能直接与三维末端误差计算夹角。模型是否只给符号、是否还有可信幅度，仍需从代码核实；全零动作单独统计。
- **动作生成函数。**用户用 optimizer 类比：函数结合当前关节姿态、任务误差、模型判断与历史反馈，具体 sample 下一组关节增量。此处 sample 暂统称产生候选动作，不预先承诺必须随机、多候选或在线物理试错。
- **简单实现候选。**统一调幅、逐关节调幅、带方向修正的采样分布都可以放入同一框架；标量调幅最容易分析，但逐关节缩放会改变整体方向。是否必须遵守模型符号是下一项待决边界。
- **有限预算。**限制每次执行的动作范数、速度与时长；校准不能免费试错，也不能默认真实机械臂可恢复到执行前状态。
- **在线与 oracle 分开。**仿真真值梯度／Jacobian 可以诊断方向与理论条件；实际控制器若使用这些额外信息，必须显式标注，不能与纯观测控制混报。

候选统一写法是

\[
\Delta q_t\sim Q_\phi(\cdot\mid q_t,e_t,s_t,\mathcal H_t),
\qquad q_{t+1}=q_t+\Delta q_t,
\qquad e_t=h(q_t)-x^*.
\]

Q 是动作生成函数或分布，H 是过去的动作和执行结果；确定性函数是分布集中在一个动作上的特例，φ 不要求必须由神经网络学习。这个公式是框架定义的提案，不是用户已批准的具体算法。

optimizer 类比对应为：关节角 q 像待更新参数，任务误差 V 像 loss，模型判断 s 像不精确的方向建议，Q 像把建议变成具体更新量的 optimizer。**类比边界：Jev 输出尚不是可反向传播的真实梯度，机器人执行也不是能任意撤回的数值迭代。**

若局部位置误差 V(q)=‖h(q)−x*‖²/2，则真正的关节空间梯度为 ∇V(q)=J(q)ᵀe；这里 J=∂h/∂q。姿态误差需另选局部表示与权重，不能把欧拉角差在全局直接套入此式。算法不一定要显式恢复整个 J，可以只估计足以指导下一步的局部响应。

最小实现必须与合理调参的固定关节增量、简单自适应规则及无需模型的反馈控制比较；不能只因为采样函数更复杂就视为贡献。

## 5. 数学起点：哪些条件能支持步数界

以下是 Agent 推导的**标准平滑下降框架下的候选命题**，用于定位缺口，不是新定理或已验证结论，也未写入 `method.md`。

限于单阶段、局部准静态、无观测噪声的理想情形。令 V(q)≥0 为可测误差，零值对应本阶段目标，并令 g_t=∇V(q_t)。以下先分析动作生成函数 Q 的确定性特例；假设所有更新及其线段均留在同一个有效区域内：

1. V 的梯度为 L-Lipschitz；且满足局部 PL 条件 ‖g_t‖²≥2μV(z_t)。
2. 最终执行的单位关节方向为 d_t，其下降斜率 a_t=−g_tᵀd_t 满足 a_t≥ρ‖g_t‖，ρ>0；若 Q 改变模型方向，必须分别评价原始模型与执行方向。
3. 校准估计满足 |â_t−a_t|≤δa_t，0≤δ<1。
4. 执行更新 q_{t+1}=q_t+α_t d_t，α_t=â_t/L 可实现且未被动作边界截断。

由平滑下降不等式，

\[
V(q_{t+1})\le V(q_t)-\alpha_ta_t+\frac{L\alpha_t^2}{2}
=V(q_t)-\frac{a_t^2-(\widehat a_t-a_t)^2}{2L}
\le(1-\chi)V(q_t),\quad
\chi=\frac{\mu\rho^2(1-\delta^2)}{L}.
\]

若 0<χ<1 且 V(q₀)>ε，则充分的更新次数为

\[
N_\varepsilon\le\left\lceil
\frac{\log(V(q_0)/\varepsilon)}{-\log(1-\chi)}
\right\rceil.
\]

这表达了一个条件式关系：方向更有用、校准更准确时，此理想框架给出的上界更好。但至少还有五个未解问题：

- 真实方向会出错，不能直接假设每一步均有固定正余弦下界；正确率高于 50% 也不足以替代带幅度的期望进展条件。
- L、μ、ρ、δ 未必已知或能低成本估计；接近目标时相对误差条件尤其强。
- 动作限幅、噪声、延迟、动态障碍与接触切换会改变这个结论。
- N 是更新次数。只有每步恰好调用一次且校准不额外调用时，才能等同模型请求次数；物理试探仍要计量。
- 两个算法上界的比值不等于实际加速比。尚未建立最优下界、与某基线的理论加速保证或整任务成功保证。

对于真正的随机采样 Q，在所有候选动作线段仍处于同一个 L 平滑区域的条件下，应从条件期望出发：

\[
\mathbb E[V(q_t+\Delta q_t)\mid\mathcal F_t]
\le V(q_t)+g_t^\top\mathbb E[\Delta q_t\mid\mathcal F_t]
+\frac L2\mathbb E[\|\Delta q_t\|^2\mid\mathcal F_t].
\]

F_t 包含采样前已知的信息。上式显式保留动作二阶矩，说明“平均方向正确”还需控制幅度与方差；不能把随机动作的均值直接代入确定性收敛界。若先采样多个候选再选择，应分析选择后的实际执行分布，并计入全部候选评估成本。

**一个立刻成立的反例：**V(x)=x²/2，方向始终为 −sign(x)，固定幅度 h，x₀=h/2。系统会在 ±h/2 间振荡，无法达到 ε<h²/8。这说明“方向对了”仍然需要步长与精度条件。

真正值得推进的理论任务是：在允许的黑箱反馈和预算内，对校准误差给出可操作条件，并说明包含校准成本后何时仍然获益。若做不到，论文应收缩为可复现诊断与经验规律，而不宣传普适成本保证。

## 6. 评价口径（待用户拍板）

建议把主指标定为：**在相同成功标准下，达到给定总体成功率所需的总模型调用预算**，而不是只统计成功轨迹的平均步数。

定义 S(c) 为在至多 c 次模型请求内成功的比例，以同分布初始条件与配对种子估计。候选指标 C(p₀)=inf{c:S(c)≥p₀}；目标成功率 p₀、精度 ε、预算上限及非劣阈值都需事先确定。达不到目标时报告“未达到”，不能删去失败轨迹。阶段判断、视觉解析、重复询问和校准相关的模型请求都计入总量，并按模型拆分。

同时报告：物理执行／校准试探次数、墙钟时间、调用费用、成功率、目标误差、碰撞／违规率，以及方向余弦与实际单步进展的分布。批量问题数另记，不能把一次请求中的六个问题算成六次 API 调用。

录音中的“减少 30%”保留为讨论过的目标例子，不写成已确认阈值或预期必达结果。

## 7. 能推翻主张的实验设计（全部为候选，尚未执行）

| 要回答的问题 | 公平比较 | 何种结果会削弱主张 |
|---|---|---|
| Jev 的方向是否提供额外价值？ | 同观测下，模型方向对比误差符号／比例反馈等简单规则 | 简单规则同样好或更好，且模型没有额外语义能力收益 |
| 定量校准是否超越步长调参？ | 调参充分的固定步长、现有分档规则、同方向自适应幅度 | 只赢很差的固定步长，或控制动作上限后收益消失 |
| 理论量能预测结果吗？ | 控制方向噪声、响应增益或局部曲率，比较预测趋势与实测成本 | 更好的方向／估计量不对应更好的成本，或只能事后拟合 |

| 加上额外代价还划算吗？ | 将所有调用、试探、恢复与失败计入 | 步数虽少，总调用／时间不降，或成功率明显降低 |

## 8. 定稿前逐轮收敛的问题

按依赖顺序讨论，每轮只问一项：动作函数对模型方向的使用边界 → 同等观测下为何需要 Jev → 第一篇理论适用范围 → 成功与成本口径 → 可用数据／设备／预算 → 最小方法与文献差异。

**已确认：**用户在解释后明确选择关节控制，并强调通过函数具体 sample 动作，类比 optimizer。

**下一问：**动作函数必须遵守 Jev 给出的各关节正负方向，还是可以在执行反馈支持时改变它？建议框架允许修正，把仅调幅作为更简单的特例和对照；这是 Agent 建议，尚未拍板。

直观区别：末端控制是告诉机器人“夹爪往右移 2 厘米”，底层控制器负责换算各关节怎么转；关节控制是直接告诉机器人“第 1 个关节增加若干度、第 2 个关节减少若干度”，夹爪最终往哪走取决于当前姿态。即使都输出六个数，“位置三维＋朝向三维”也不等于“六个关节角”。

本稿已经能供讨论，但尚不能直接宣称“模型理解机器人动力学”“首个残差控制框架”“普适最小采样次数”或“已降低 30% 成本”。正式 `idea.md` 的目标与主指标、`method.md` 的定义与结论，待上述问题收敛后再写入。
